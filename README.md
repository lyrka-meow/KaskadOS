KaskadOS
========

Управление сборками
-------------------

Соберите настоящий Qt-бинарник один раз:

```bash
cd /home/ll/KaskadOS && make manager
```

После этого менеджер запускается напрямую, без Bash-обёртки:

```bash
/home/ll/KaskadOS/build/kaskados-manager/kaskados-manager
```

Менеджер не проверяет обновления сам и не скачивает пакеты при сборке ISO.
Проверка, загрузка и офлайн-сборка являются отдельными явными действиями.

Кэш и сборка ISO
-------------------

Нужные компоненты можно пересобрать по одному или списком в менеджере. Команда
ниже только упаковывает уже готовые локальные сборки в профиль ISO:

```bash
make live-profile
```

После любой пересборки компонента профиль и офлайн-кэш считаются
устаревшими. Сначала нужно заново упаковать профиль, а затем обновить
кэш. Сборка ISO не разблокируется, пока оба эта этапа не завершены.

В дереве менеджера точные имена пакетов не заменяются общими названиями.
«Требования ISO» — это корневые пакеты профиля и прямые требования собранных
компонентов. «Зависимости пакетов (pacman)» — точный транзитивный состав,
который `pacman` разрешил для текущих версий.

Если нужно намеренно обновить все внешние исходники, локальные пакеты и полный
кэш, для этого есть отдельная сетевая команда:

```bash
make iso-update
```

Загрузка полного офлайн-кэша пакетов тоже выполняется только по явной команде:

```bash
./scripts/cache-iso-packages.sh
```

Если пакеты уже есть в кэше, после переупаковки профиля их можно проверить и
заново собрать точный офлайн-репозиторий без сети:

```bash
./scripts/validate-iso-cache.sh
```

Если офлайн-проверка сообщит о недостающей версии, только тогда нужно запускать
сетевое обновление нужного пакета или всего кэша.

После первого полного обновления отдельный пакет и его зависимости можно обновить так:

```bash
make iso-update-package PACKAGE=linux
```

Сборка использует только локальный `file://`-репозиторий и не обращается к
интернет-репозиториям:

```bash
make iso
```
