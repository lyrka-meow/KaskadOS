# Kaskad product naming

The desktop is a first-party part of the distribution. Its public component
names are therefore derived from the distribution name rather than presented
as separate products:

- **KaskadOS** — the complete distribution;
- **Kaskad DE** — the desktop environment and the Wayland session shown by a
  display manager;
- **Kaskad Compositor** — the window manager and Wayland compositor;
- **Kaskad Shell** — panels, docks, settings, overlays, and other DE surfaces;
- **Kaskad Portal** — the XDG desktop portal backend;
- **Regalia** — the only VPN subsystem integrated into KaskadOS.

Lowercase names such as `kaskad-desktop`, `KaskadDesktop`, `KaskadShell`, and
`kaskad-shell` are implementation identifiers and compatibility contracts, not
public product names. Standard technical terms such as `.desktop` files and
XDG desktop portals keep their protocol-defined spelling.

Never use “Cascade” as an alternative spelling. The product name is always
`KaskadOS` for the distribution and `Kaskad DE` for the environment.
